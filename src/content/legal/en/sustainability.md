Every website and every cloud system uses energy: in data centres, in networks and on the devices of the people who use them. At Trislab we treat that energy as a cost to measure and keep low, in our own systems and in the systems we build for our clients.

## The carbon footprint of this website

| Indicator | Value |
| --- | --- |
| Average page weight | about 145 KB |
| Emissions per page view | about 0.02 g CO₂e |
| JavaScript | none |
| Cookies, trackers, third-party scripts | none |

The figure is calculated with the Sustainable Web Design model, version 4, using the open-source CO2.js library of the Green Web Foundation. It covers the data centre, the network and the visitor's device, and it does not assume that the energy is renewable, so it errs on the side of caution. A typical web page today weighs more than 2 MB, over ten times as much as a page of this website.

## How we keep it low

- **Static pages.** Every page is prepared in advance and served as a finished file. No server computes anything when you visit.
- **No JavaScript.** The pages run no scripts and no frameworks in the browser.
- **No tracking.** No cookies, no analytics and no third-party content, so your browser downloads only what you see.
- **Lean assets.** One self-hosted font, icons drawn in a few lines of code, and no stock photography or video.
- **A weight budget.** Every change to the website is checked automatically and is rejected if a page grows beyond its budget.
- **Served nearby and cached.** The pages are delivered from data centres close to the visitor, and stylesheets and fonts stay in the browser's cache, so a second page loads only its text.

## Our cloud

We run our own systems on Microsoft Azure and Google Cloud, in data centres in the European Union. Both providers have set targets to run on carbon-free energy and report the emissions of the resources their customers use. We use these reports to follow the emissions of our cloud resources and review them once a year, together with the footprint of this website.

## In our work for clients

The same principles guide the systems we design and build: resources sized to the real load, efficient code, and data kept only as long as it is needed.
